AWS STRANDS AGENTS ROADMAP (2026)

Step-by-step guide to production agents with AWS Strands Agents

Strands is AWS's open-source, model-driven agent SDK: give an agent a model, a prompt and tools, and the model plans the loop itself. Add Graph, Swarm or agents-as-tools when you need structure, and deploy to Bedrock AgentCore, Lambda or containers.

01

Setup, Models & Credentials

  • Install strands-agents and the community tools package
  • The default model is Amazon Bedrock; BedrockModel, AnthropicModel, OpenAIModel, LiteLLMModel and OllamaModel are drop-in providers
  • strands-agents
  • strands-agents-tools
  • BedrockModel
  • AnthropicModel
  • LiteLLMModel

02

Harness, Runtime & Sandbox

  • An Agent is a model, a system prompt and tools running the event loop: the model reasons, calls tools, reads results and repeats until it stops
  • Calling the agent returns an AgentResult with the stop reason, final message and metrics
  • Sandbox: The loop runs in your process; AgentCore Runtime adds session isolation
  • Agent()
  • @tool
  • system_prompt
  • AgentResult
  • stop_reason

Errors, Retries & Limits

  • The event loop retries throttled model calls with backoff and lets the conversation manager shrink context on overflow
  • Hooks such as AfterToolCallEvent observe or rewrite failing tool results; typed exceptions surface the rest
