Python Demo: See Your Code Run Line by Line

A Python program runs one line at a time. In this lab you pick a lesson, then step through it and watch each line change the variables, call functions, build objects and print output. Press Run to execute the same code in real Python in your browser.

How to use this lab

Play runs the program step by step, ← and → move one step, and clicking a line number jumps to that line. The code is read-only; use Copy code to try it in your own editor.
