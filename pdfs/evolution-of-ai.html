Traditional ML: learn the rules from data

Instead of writing rules, we show the algorithm thousands of labelled examples and it finds the pattern. The output is a prediction with a confidence score, not a fixed answer.

The ML lifecycle

Featuresengineer signals
Trainfit the model

Deployserve & monitor

Three ways to learn

  • Supervised: labelled data (regression, classification)
  • Unsupervised: find structure (clustering, anomalies)
  • Reinforcement: learn by reward (games, robotics)

Classic algorithms

Generative AI: from inspector to creator

Traditional ML inspects data and labels it. GenAI creates something new: text, code, images, audio. Foundation models learn from huge amounts of data, then follow plain-language prompts.

AI Agents: LLM + tools + memory + goal

An agent doesn’t just reply. It decides what to do next, calls real tools (APIs, databases, code, browsers) and uses the results to complete a task for you.

How an agent runs a task

Goaluser intent
Planbreak into steps
Tool callAPI · SQL · search
Observeread the result
Respondanswer or act

Anatomy of an agent

  • Brain: the LLM that reasons
  • Tools: functions, MCP servers, APIs
  • Memory: short-term context + long-term vector store
  • Planner: decides the next step
  • Guardrails: permissions, policies, limits

Key patterns

  • ReAct: reason, then act, in turns
  • Function / tool calling
  • Agentic RAG: the agent decides what to retrieve
  • Multi-agent: a supervisor routes work to specialist agents

Agentic Loops: think · act · repeat

The agent runs in a loop. It acts, checks the result against the goal, reflects, and goes again until the job is done, the budget runs out, or a human steps in.

The loop

  • Reflection: the agent critiques its own draft
  • Plan-and-execute: plan once, run the steps, re-plan when something fails
  • Evaluator–optimizer: one model writes, another grades it
  • Human-in-the-loop: a person approves risky actions
  • Stop conditions: goal met, max steps, or token/cost budget used up

Orchestration

  • State machines & graphs (LangGraph)
  • Subagents with their own context
  • Parallel workers, then merge the results
  • Long-running, resumable runs

Across domains

  • Software: write code → run tests → fix
  • Finance: reconcile ledgers until they balance
  • Retail: tune pricing, measure, adjust
  • Research: search, read, cite, verify

Controls that make loops safe

Token & cost budgetsTracing & observabilityPermission boundaries Sandboxed executionEvals & regression testsAudit logs

The Future: AI as a colleague

Each era built on the one before it. The next one is agents that work for hours or days, cooperate with each other, and operate in the physical world, under strong governance.

Trends to watch

  • Long-horizon agents: multi-day autonomous work
  • Multi-agent organisations: teams of specialist agents
  • Computer use: agents that operate apps and browsers
  • Embodied AI: robotics guided by foundation models
  • Small on-device models: private and low-latency

Standards & trust

  • Open protocols: MCP, agent-to-agent (A2A)
  • Governance: data lineage, Purview, Unity Catalog
  • Regulation: EU AI Act, model risk management
  • Safety: evals, red-teaming, alignment
