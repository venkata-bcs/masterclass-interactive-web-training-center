Meet the agent.
A model that can look, decide and act.

An AI agent is a language model with three extra things: orders (its role and instructions), gear (tools, knowledge and memory) and limits (guardrails and human approval). Brief one below and watch the same task run three ways: as a plain model call, as a fixed workflow and as an agent. Each one breaks in a different place.

What you just saw

Use the simplest thing that works

MODEL

A plain model call

Best for words: drafting, summarising, explaining. Cheap and fast, but it only knows what it was trained on and cannot do anything.

WORKFLOW

A fixed workflow

Best when the path is known in advance. Predictable, testable and cheap to run, but it breaks on the first case nobody coded for.

AGENT

An agent

Best when the next step depends on what it finds. It handles surprises, but it costs more, varies more and needs firm limits.
